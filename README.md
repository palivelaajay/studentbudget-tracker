# FAMAM BOT 🚀

FAMAM BOT is a MERN stack web application that helps users track product prices from e-commerce websites.

Users can:

* 🔐 Register & Login securely
* 📦 Add product URLs
* 💰 Set budget prices
* 🔄 Automatically monitor product prices using cron jobs

The system uses web scraping to fetch live product prices and stores product data in MongoDB.

## 🛠 Tech Stack

* React
* Node.js
* Express
* MongoDB
* JWT Authentication
* node-cron

## 🚀 Features

* User Authentication
* Product Tracking
* Budget Monitoring
* Auto Price Updates
* Delete & Update Products
